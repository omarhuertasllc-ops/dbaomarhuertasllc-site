The proof behind every automation

Sample format

Runbook snippet

Go-live: scoped app release
1. Confirm change is Approved
2. Back up: export update set
3. Promote in the window
4. Run smoke tests (ATF)
5. Verify event logs are clean
Rollback
  Back out update set, re-run
  smoke tests, notify owner

Written so someone who was not in the room can run it.

Sample format

Upgrade-safe checklist

  • Built in its own application scope
  • Base-system records extended, not edited
  • Roles and ACLs defined per table
  • ATF covers happy and failure paths
  • Skipped-changes review after each upgrade
